[[maven-plugin]]
= The Maven plugin

The Maven plugin (`io.codelaser:maddi-mvnplugin`, on Maven Central, goal prefix `maddi`) derives the input
configuration from the Maven project model (compile and test source roots, and the dependency classpath resolved via
Maven's own resolver) and, like the Gradle plugin, hands it to the Java analyzer.

== Using it

[source,xml,subs="attributes"]
----
<plugin>
    <groupId>io.codelaser</groupId>
    <artifactId>maddi-mvnplugin</artifactId>
    <version>{maddi-version}</version>
    <configuration>
        <analysisSteps>modification</analysisSteps>
    </configuration>
</plugin>
----

[source,console]
----
$ mvn maddi:run
----

== Goals

[cols="1,3",options="header"]
|===
| Goal | Does

| `run` | Parse, prep- and modification-analyze the project; write results.
| `write-input-configuration` | Write the computed input configuration to JSON (`outputFile`).
| `compile-analysis-hints` | Compile hand-written analysis-hint sources (`inputDirectory`) into result `.json`
files (`outputDirectory`); see <<analysis-hints>>, use case 2.
| `write-analysis-hints` | Generate first-cut analysis-hint skeletons for the library types the
project calls into (use case 3).
| `statistics` | Method-call-frequency histograms.
|===

== Configuration

The parameters common to all goals mirror the Gradle extension (<<gradle-plugin>>): `analysisSteps`,
`analysisResultsDir`, `incrementalAnalysis`, `parallel`, `quiet`, `warnNearMisses`, `debug`, `jmods`, `jre`,
`sourceEncoding`, `excludeFromClasspath`, `workingDirectory`, `preloadAnalysisResultsDirs`, and the hint options
`analysisResultsTargetDir`, `updatedHintsDir`, `updatedHintsPackage`, `hintsPackages`.
`sourcePackages` and `testSourcePackages` exist too, with the same warning as for Gradle.
The ownership pass is not available through the Maven plugin; use the command line.

== The `--add-exports` requirement

Unlike Gradle (which forks a worker), a Maven goal runs in-process, so the Maven JVM itself must be
started with the javac `--add-exports` from <<overview>>. Put them in `.mvn/jvm.config` or `MAVEN_OPTS`:

[source]
----
# .mvn/jvm.config
--add-exports jdk.compiler/com.sun.tools.javac.api=ALL-UNNAMED
--add-exports jdk.compiler/com.sun.tools.javac.tree=ALL-UNNAMED
--add-exports jdk.compiler/com.sun.tools.javac.code=ALL-UNNAMED
--add-exports jdk.compiler/com.sun.tools.javac.parser=ALL-UNNAMED
--add-exports jdk.compiler/com.sun.tools.javac.util=ALL-UNNAMED
----

Maven itself must run on JDK 25 or later for these goals.
