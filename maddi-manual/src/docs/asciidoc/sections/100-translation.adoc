[[translation]]
= Translating a project

The same command line that analyses a project can translate its main sources into another language.
The analysis is what makes the translation more than a change of syntax: the verdicts decide what the types of
the target language say.

[source,console]
----
$ maddi --compile-log build.log --translate kotlin --translate-output kotlin-src
$ maddi --compile-log build.log --translate csharp --translate-output csharp-src
----

[cols="1,3",options="header"]
|===
| `--translate` | Produces

| `kotlin` | Kotlin sources, as a source tree by package.
| `kotlin-stubs` | Kotlin in which each method body is a `TODO` stub, for another translator (a language model, for
example) to write; the stubs are described in `maddi-bodies.json`.
| `csharp` | C# sources, with a `Translated.csproj` that builds them. Experimental.
| `rust` | Rust. Experimental.
|===

== What the analysis contributes

Unless `--analysis-steps` says otherwise, a translation first runs the modification analysis and the nullability
pass. Their verdicts decide:

* `T` or `T?` for every field, parameter, return value, type argument and array element;
* where a `!!` (in C#, a `!`) is needed, and where Kotlin's own smart cast makes it unnecessary;
* which collections are read-only: a parameter whose list is never structurally modified becomes a `List`, not a
  `MutableList`.

With `--analysis-steps none` the translation runs without these facts, and has to assume the worst.

`--ownership` and `--closed-world` (<<command-line>>) matter most for a translation into a language without a
garbage collector: they say which fields own their objects, which methods return a fresh one, and which
parameters are only borrowed.

== The report

`translation-report.txt` in the output directory lists the messages of the translation, and the places where it
moved a possible `NullPointerException` from a dereference to an earlier assertion.
A source file on which the translation crashed is left out and listed in the report, and the run exits with a
non-zero code.

A project with Kotlin sources cannot be translated: there is no single Java program to translate (<<kotlin>>).
