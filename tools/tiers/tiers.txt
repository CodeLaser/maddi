# The tier of every maddi module: the source of truth for tools/tiers/check_tiers.py.
# See docs/roadmap/split-maddi-into-three-repositories.md §1-§2.
#
#   base  depends on nothing above it, in any scope (main, test, testFixtures)
#   mod   depends on base only
#   ext   COMPILES against base only; mod may appear only in runtime configurations
#         (runtimeOnly, testRuntimeOnly, shade not extended by implementation)
#
# Lines:  <module> <tier>
#         require-runtime <module>     an ext module that must carry mod at run time
#
# The assignments below are the TARGET of the split, not the state of the code: the check fails until the
# stages that make them true have landed.
