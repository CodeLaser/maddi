- **`maddi-inspection-openjdk/DESIGN-drop-javac-ast.md`** — Option B landed and is gated; options C and D

  They are now the only specification of the `EVENTUALCLUSTER` behaviour, so they should be reframed as

- **`maddi-modification-link/sv-integration-plan.md`**, **`sv-semantic-differences.md`**,
  **`sv-engine-differential-worklist.md`** — the port happened; the last of the three already declares itself

### 3.4 Not a document problem, but found by this audit

**`docs/partial-reparse-rewire.md` §10.** Auditing that document is what turned up a real defect in the
generation feature committed the same day: `generate()` tears the javac task down, and the inspector retains
that task to serve `CompiledTypesManager.getOrLoad`. With `setGeneratedClassesDirectory` on, on-demand
compiled-type loading throws. The document had flagged exactly this in §7.1 as its highest-priority risk, in
June. Fix options are in that §10.

### 3.5 Stale run instructions (unrelated to implementation)

`testgradleplugin-analyzer/README.md`, `testgradleplugin-writeaapi/README.md` and
`testmvnplugin-export/README.md` (2025-08-18, 9–15 lines) tell the reader to `cd analyzer-run` (no such
directory), run task `e2immu` (now `e2immu-analyzer`), and install `e2immu-run-mvnplugin` (now
`maddi-mvnplugin`). Rewrite or delete — as they stand they cannot be followed.
