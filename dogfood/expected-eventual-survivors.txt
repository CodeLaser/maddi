# The eventual-immutability ratchet baseline: types that survive the EventualCluster contraction
# on the composed dogfood run (maddi analysing its own CST).
#
# One fully-qualified type name per line, sorted. Blank lines and '#' comments are ignored.
# Maintained by TestEventualRatchet (maddi-run-openjdk, slowTest). See docs/eventual-design-improvements.md
# section 1, and docs/eventual-info-hierarchy.md for the diagnosis recipe when a type disappears.
#
# A type LOST from this list means a commit has cost it its eventual verdict -- that is the regression
# the ratchet exists to catch (the ProvidesImpl incident went undetected for a week).
# A type ADDED is progress: re-generate this file from build/eventual-survivors-actual.txt.
#
# SCOPE: cst-api, cst-analysis and cst-impl are analysed as source and are what this baseline defends.
# maddi-support and maddi-util arrive as jars pinned by the dogfood build (currently 0.8.2, while the
# project is at 0.9.0), so a change to either does NOT reach this run and reads as "no change". Bringing
# them in means bumping those pins, re-publishing the plugin, regenerating the input configuration --
# and re-deriving this baseline, since the jars moving forward will move verdicts with them.
#
# Baseline re-derived 2026-08-03 under the DEFERRAL round (docs/eventual-info-hierarchy.md section
# "The deferral round"): the eventual family is cleared and re-derived at the terminal certification
# point over the settled state, so the walks and the assumption ledger are a function of the fixpoint
# alone.
# BASELINE 2026-08-04b (the FF-cap world): 285 types, R19/R20 byte-identical in
# ~/git/ws/eventual/questR-20260804. The isMutable(@FinalFields) hierarchy exit no longer sinks a
# subtype to MUTABLE in after-mark mode: a @FinalFields super caps the sub at @FinalFields via the
# hierarchy min (the sub inherits the super's post-mark-mutable content, no more). One transiently
# capped write on Expression had zeroed the whole Element family through that exit; with the cap the
# family floors at FF. 194 @FinalFields + 91 @Immutable(hc) survivors; Element stands at
# @Immutable(hc=true) with the 60-label union; the arithmetic five, the statement family, ModuleInfo
# and the Comment family are all in. Fernflower A/B: one pure addition
# (SwitchOnReferenceCandidate FF(after=myTempVarAssignments)), zero losses. The residual race now
# degrades hc to FF instead of zeroing -- the deferral design's remaining decision.
#
# BASELINE 2026-08-04c (the deterministic terminal epoch): SAME 285 types, membership unchanged; the
# warm-up sweep is now committed and the composition is 163 @Immutable(hc) + 122 @FinalFields,
# byte-identical across every measured pair (Y1..Y4 in ~/git/ws/eventual/questR-20260804). The old
# hc/FF coin (179/106 vs 165/120) is closed by the ⊆ tier-uniformity fix in LinkToField; the runtime
# family survives honestly through the primitives() immutable copy + @Independent(hc=true) contract
# (the live values() view was a real soundness hole the tier-uniform analyzer caught).
